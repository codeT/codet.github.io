# 姚工的备份

个人技术博客与记忆备份，记录技术文章、学习笔记与生活片段。

- 在线访问：https://codet.github.io
- 仓库地址：https://github.com/codeT/codet.github.io

## 本地预览

安装依赖后启动 Jekyll 服务：

```bash
bundle install
jekyll serve
```

或使用 npm 脚本（需 Node.js）：

```bash
npm install
npm run watch
```
